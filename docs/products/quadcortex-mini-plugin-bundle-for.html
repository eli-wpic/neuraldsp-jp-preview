Archetype: Fortin Nameless Suite Xについて

2018年、私たちは Fortin Nameless Suite を発表しました。それは常識を打ち破り、ギター・トーンそのものの本質を再定義した、謎めいた傑作でした。あれが新たな時代の幕開けだったのです。そして6年後——“あの”大物が帰ってきました。

Fortin Nameless Suite X は、6年にわたるサウンドの進化が結実した存在であり、世界で最もアグレッシブなアンプを生み出し続ける Mike Fortin の妥協なきアプローチから着想を得た、芸術と技術の融合体です。彼が精密に設計した“残虐さ”は、今日でも業界の伝説的アーティストたちのサウンドの中核であり続けています。

地獄のような歪みを解き放ち、想像の限界をも超えるモンスターアンプの咆哮に魅了されてください。それは、未知なる領域へあなたを誘うでしょう。
