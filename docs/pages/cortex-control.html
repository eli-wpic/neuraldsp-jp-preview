Cortex Control™

Quad Cortex専用フル統合型デスクトップコントローラー

Windows

NeuralDSP アカウント

Cortex Control™および Cortex Cloud™をご利用いただくには、専用のアカウントが必要となります。

アカウントを登録

Cortex Controlは、洗練された直感的なデスクトップインターフェースで、Quad Cortexのあらゆる機能や設定を簡単に操作できます。

数秒で起動

Cortex Controlは数秒で起動し、Quad Cortexの現在の状態を瞬時に同期。作業の流れを妨げることなく、すぐに前回の続きから操作を再開できます。

最適化されたワークフロー

直感的なマウス操作とキーボードショートカットにより、パラメータの調整、ファイル管理、各種操作、Cortex Control内のナビゲーションがスムーズかつ効率的に行えます。

一括操作

プリセットを複数選択して、コピー、いいね、アップロード、ダウンロード、削除が数クリックで完了。同様に、Neural CaptureやIRもまとめて編集、アップロード、ダウンロード、削除が可能です。

ローカルバックアップ

Cortex Controlを使えば、Quad CortexのローカルバックアップをPC上に直接作成・管理できます。必要なだけ何度でもバックアップを作成可能です。

バックアップの名前変更、更新、削除、呼び出しが素早く行えるクイックアクションにより、バックアップ管理が簡単かつ効率的に行えます。

USB経由のインターネット接続

Quad Cortexは、パソコンと接続されたUSBケーブルを通じてインターネットにアクセスできます。これにより、Wi-Fi環境に依存せず、常に安定したインターネット接続が可能です。Cortex Controlを起動中は、Quad CortexはUSB経由のインターネット接続を優先します。

IRのインポート

Cortex Controlを使えば、IRをQuad CortexやCortex Cloudプロフィールに簡単に追加できます。IRライブラリを開き、IRファイルをドラッグ＆ドロップするだけでOK。アップロード先に応じて、IRはすぐにQuad CortexまたはCortex Cloudアカウントで使用可能になります。

ライブチューナー

チューナー画面を開かずに素早くチューニング。ユーティリティバーのチューナーボタンをCMD（Mac）/CTRL（Windows）を押しながらクリックすることで、ライブチューナーを切り替えられます。

オーディションデバイス（試聴デバイス）

The Grid上のデバイスをクリックし、次にDevice List内の別のデバイスをクリックすることで試聴（オーディション）が可能です。試聴中のデバイスを再度クリックすると、The Grid内の既存デバイスと置き換えて追加されます。変更をキャンセルする場合はESCキーを押してください。

Neural Captureの作成

Neural Captureの作成プロセスは、Cortex Control上ですべて完結できます。

Windows最小動作環境

Intel Core i3 プロセッサ（i3-4130 / i5-2500以上）

AMD クアッドコアプロセッサ（R5 2200G以上）

RAM 8GB以上

Windows 10以上

※ Cortex Controlの動作には最新のCorOSおよびWindows USBオーディオドライバーが必要です。

macOS最小動作環境

Intel Core i3 プロセッサ（i3-4130 / i5-2500以上）

または Apple Silicon（M1以上）

RAM 8GB以上

macOS 11 Big Sur以上

※ Cortex Controlの動作には最新のCorOSが必要です。

macOSおよびWindows向けに無料提供

今すぐmacOSまたはWindows向けにCortex Controlをダウンロード。

ダウンロード

Cortex Cloud

iOS と Android 対応の Cortex Mobile アプリを使って、ユーザー、プリセット、Neural Capture を発見しましょう。

Neural DSP アカウントを Quad Cortex にリンクすることで、バックアップの作成、コンテンツの共有、他のユーザーからのアイテムのダウンロードが可能になります。

さらに、インパルスレスポンス（IR）ライブラリも利用できるようになり、IR を Quad Cortex に転送したり、アカウントに保存された IR を管理することもできます。
