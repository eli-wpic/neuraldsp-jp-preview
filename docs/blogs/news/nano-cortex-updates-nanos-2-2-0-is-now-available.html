NanOS 2.2.0 がリリースされました — Neural Capture V2 Player、トレモロ、サム出力など新機能が多数追加！

2025.11.28
.blog-post-image { width: 100%; height: auto; display: block; margin: 2rem 0; }


NanOS 2.2.0 のリリースを発表できることを嬉しく思います。今回のアップデートでは Neural Capture Version 2 Player をはじめ、多くのユーザーから要望の多かった 新しいトレモロエフェクト、サム出力（自動モノラル化） など、Nano Cortex の使いやすさと性能を向上させる様々な機能が追加されています。

Nano Cortex をご利用のすべてのユーザーに、NanOS 2.2.0 へのアップデートを推奨します。アップデート手順については、Nano Cortex の更新ガイドをご覧ください。

Nano Cortex の詳細はこちら。

NanOS 2.2.0 の新機能

Neural Capture Version 2 Player

NanOS 2.2.0 では、Cortex Cloud を通じて学習され、高解像度かつより詳細な結果を提供する Neural Capture の進化版である Neural Capture Version 2 に対応しました。
このアップデートにより、Nano Cortex は Quad Cortex で作成された V2 Neural Capture を読み込み・再生 できるようになりました。
現在、V2 キャプチャの作成は Quad Cortex のみ で可能で、Nano Cortex での V2 キャプチャ作成対応は開発中です。

Neural Capture V2 の性能を Nano Cortex 上で体験していただくために、41 種類のデバイスから合計 669 個の V2 キャプチャ を、ダウンロード可能な Cortex Cloud プロファイルに追加しました。

V1 と比べて、Neural Capture V2 はダイナミクスの精度とリアリズムが大幅に向上しており、特にファズ、コンプレッサー、レスポンスの早いアンプなど、複雑でタッチセンシティブなデバイスにおいてその効果が顕著です。これにより、ヴィンテージファズのダイナミックなクリーンアップ挙動、サグによるパワーアンプの自然な膨らみ、スタジオコンプレッサーの高速トランジェントといった特性を、現在市場で最も正確に捉えるソリューションとなっています。また、ブレンドノブなどのコントロールも、より高い精度でモデリングされています。

V1 と V2 はそれぞれ得意分野があります。V1 は高速・効率的・完全オフラインで動作し、多くのアンプ、キャビネット、オーバードライブに最適です。一方、V2 はよりダイナミックで表現力の高いデバイス向けに設計されており、最高レベルのディテールとフィールを提供します。

Neural Capture V1 と V2 の違いについてさらに詳しく読む。

Cortex Cloud オフラインモード

モバイル端末がインターネットに接続されていなくても、Cortex Cloud アプリでデバイス設定にアクセスできるようになりました。

自動モノラルサム（Automatic Sum to Mono）

この機能を有効にすると、Output 1L または Output 2R のどちらか一方にのみケーブルが接続されている場合、Nano Cortex はすべての出力信号を自動的にモノラルにサムします。

トレモロ（Tremolo）

新しいトレモロエフェクトがエフェクトライブラリに追加されました。
Post Effects Slot 1 に読み込むことができます。

キャプチャ試聴（Capture Auditioning）

Cortex Cloud アプリを使って、キャプチャや IR を素早く試聴できるようになりました。
クラウド上またはデバイス内から、ワンタップで試聴が可能です。

クラウドバックアップ（Cloud Backups）

Nano Cortex のバックアップを最大 5 つまで作成し、Cortex Cloud に保存できます。

プリセット並べ替え（Preset Rearrange）

Cortex Cloud アプリでプリセットをドラッグ＆ドロップして簡単に並べ替えできるようになりました。

修正点（Fixed）

システムの安定性とパフォーマンス

高速なユーザー入力や予期せぬエラーによるアプリクラッシュを防ぐため、Cortex Cloud アプリの安定性を改善。

クラウドから Neural Capture をダウンロードして割り当てた後、オーディオ出力がミュートされる可能性のあった問題を修正。

特定の Neural Capture 間を切り替える際に、ポップノイズが発生することがある問題を修正。

コンテンツ管理（Content management）

デバイスの SAVE ボタン使用時に、新しい Neural Capture が正しく保存されない問題を修正。

新しく選択したユーザー作成 Neural Capture がプリセットに読み込まれないことがある問題を解決。

Cortex Cloud アプリで、すべてのインパルスレスポンス（IR）一覧をスクロールできなかった問題を修正。

新規に保存したキャプチャが、アプリやデバイスを再起動せずとも Cortex Cloud アプリのライブラリに即座に反映されるよう改善。

ハードウェア、エクスプレッション & MIDI コントロール

エクスプレッションペダルが割り当てられたプリセットを再読み込みした際に、予期せぬ音量上昇が発生する可能性のあった問題を修正。

エクスプレッションペダルに割り当てられたパラメータが、Nano Cortex 本体のノブで調整後に最大値へ戻ってしまう問題を修正。

（例：CC#43 でチューナーを開いたときなど）MIDI コマンド受信後に、メニューから正しく退出できなかったフットスイッチの動作を修正。
