Archetype: John Mayer X 発表 ― Neural DSPとジョン・メイヤーの歴史的コラボレーション

2025.12.18
.blog-post-image { width: 100%; height: auto; display: block; margin: 2rem 0; }

ジョン・メイヤー本人と共同開発され、彼の個人所有のアンプ、エフェクト、そしてシグナルチェーンをもとにモデリングされた本プラグインは、彼の作品を、そして一世代のギタリストを定義してきた唯一無二のトーンを生み出すための、本物の基盤を提供します。

フィンランド・ヘルシンキ／2025年12月17日

Neural DSPは本日、同社の高い評価を受けているArchetypeシリーズにおける最新作であり、同社史上でも最も象徴的なコラボレーションの一つとなるArchetype: John Mayer Xを発表しました。ジョン・メイヤー本人とのパートナーシップのもと開発され、彼のスタジオおよびツアー用の実機ギアを忠実にモデリングしたこのプラグインは、過去20年間にわたり数多くの名演・名盤を支えてきたトーン、ダイナミクス、そして表現力を、かつてないほどリアルに体験できるものです。

ジョン・メイヤーのサウンドは一聴してそれと分かる存在です。タッチ、トーン、そして感情の繊細な相互作用は、長年のレコーディングとライブパフォーマンスを通じて受け継がれてきました。『Continuum』における流麗で正確なフレーズから、ライブでの空間的かつ立体的なテクスチャーまで、彼の音楽性はニュアンスとフィールを、澄み切った明瞭さとともに融合させています。

Archetype: John Mayer Xは、そのアイデンティティをひとつの深く表現力豊かなツールへと凝縮しました。彼のコアとなるトーンを形作るアンプ、ペダル、そしてポストプロセッシングチェーンをもとに構築されており、さらにジョン・メイヤー本人が制作した豊富なプリセットライブラリも収録されています。

「ジョンのサウンドは世界中のギタリストに影響を与えてきました。彼のトーンを支えるリグを、本人と直接協力しながら再現できたことは大きな喜びでした」と、Neural DSPのCEO兼共同創業者であるダグラス・カストロは語ります。
「彼のリグの反応には親密さがあります。呼吸するように鳴り、開放的で、感情を宿している。その振る舞いを捉えることは、私たちにとって最も意義深いプロジェクトの一つでした。」

ジョン・メイヤーの音楽的アイデンティティを、スタジオレディな形で

Archetype: John Mayer Xは、彼のクリーントーン、リードフレーズ、そしてタッチダイナミクスを支える中核的なアンプを基盤としています。本プラグインには、ジョン・メイヤー本人が所有する以下の3台のアンプが収録されています。

  • 1964 Fender® Vibroverb®

  • Dumble® Steel String Singer® #002

  • Two-Rock® プロトタイプ Signature #83

いずれも極めて高い精度でキャプチャされており、ヘッドルーム、レスポンス、倍音構造に至るまで、メイヤー本人が使用するそのままの状態が再現されています。

さらに本作では、Three-in-One Ampという新しいアンプも導入されています。これは、スタジオおよびライブの両方で使用されてきた、ジョン・メイヤー独自のブレンドアンプ構成を再現したものです。3台すべてのアンプとそれぞれに対応するキャビネットを、彼の正確な設定、マイク配置、EQ判断とともに統合。個別にバランス調整を行うことなく、彼の完全なシグナルパスを反映した、立体的で一体感のあるサウンドを即座に得ることができます。その結果、演奏との結びつきが強く、開放的で、まさにメイヤーらしい響きが生まれます。

Pre FX（プリアンプ前エフェクト）

プラグインのフロントエンドは、『Continuum』期のシグナルチェーンを忠実に再現し、彼のタッチ、アーティキュレーション、そして表現力を形作るペダル群を網羅しています。すべてジョン・メイヤー本人の実機からモデリングされ、実際の使用順で配置されています。

  • Justa Boost
    Keeley® Katana®をベースにしたクリーンブースト。常時オンで使用され、シングルコイルピックアップに厚みと倍音を加えます。

  • Antelope Filter
    Electro-Harmonix® Q-Tron+®をもとにしたエンベロープフィルター。「I Don’t Trust Myself (Loving You)」などで聴ける表情豊かな動きを再現。

  • Halfman OD
    ジョン自身が所有するKlon® Centaur®を再現。アンプ本来の個性を保ちながら、透明感のあるゲインと倍音のフォーカスを提供します。

  • Tealbreaker
    Ibanez® TS-10®とMarshall® Bluesbreaker® MK1に着想を得たデュアルモード・オーバードライブ。ブルース寄りのスムーズなリードから、よりワイドなブレイクアップまで対応します。

  • Millipede Delay
    Way Huge® Aqua Puss®をベースにした、アナログ感のあるショート・スラップバックディレイ。ソロ時の微妙な厚み付けに使われる、やや不安定なBBD特性を再現しています。

アンビエンス & モジュレーション

ジョン・メイヤー特有の空気感と揺らぎは、Gravity Tankによって再現されています。彼が愛用するスプリングリバーブと、長年使用してきたVictoria® Reverberatoのハーモニックトレモロ回路を融合。名曲「Gravity」へのオマージュとして名付けられたこのエフェクトは、彼の代表的なトーンの中心にある動き、奥行き、そして雰囲気をひとつの表現力豊かなコントロールにまとめています。

キャビネットシミュレーション（Cabsim）

キャビネットセクションには、各アンプに対応する実機キャビネットを収録。

  • Fender®コンボ（15インチ CTS®スピーカー）

  • Dumble®キャビネット（ヴィンテージEVM12L®搭載）

  • Two-Rock®プロトタイプ用キャビネット（Celestion® G12M Greenback®）

Post FX（ポストエフェクト）

レコーディングされたジョン・メイヤーの洗練されたサウンドを再現するため、ポストエフェクトも充実しています。

  • Dream Delay
     彼が使用するデジタルディレイに着想を得た、テンポ同期可能なクリーンディレイ。トーンコントロールにより質感を自在に調整可能。

  • Studio Verb
         HallとPlateの2モードを搭載。クリーントーンや伸びやかなリードに、温かく音楽的な奥行きを加えます。


EQ & コンプレッサー

4バンドのセミパラメトリックEQには、彼のアンプが持つ豊かな低域をバランス良く整えるためのハイパス／ローパスフィルターを搭載。
 さらに、Distressor®を参考にしたコンプレッサーを収録し、ジョン・メイヤーが実際に使用しているアタック、リリース、サイドチェイン設定を再現。彼の洗練されたダイナミクスを支える、滑らかで安定したコンプレッションを提供します。

「ジョンのトーンは、長年にわたる演奏とレコーディングの中で積み重ねられた選択の連続です。私たちはその選択をそのまま残しました。プレイヤーは、彼が立つスタート地点――落ち着きがあり、表現力豊かで、親しみのあるサウンド――から始め、そこから自分自身の音へと発展させることができます」と、カストロは締めくくっています。
